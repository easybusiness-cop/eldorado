## Why no index was created

An index must match actual equality, range, join, and ordering predicates. Without a table definition and query plan, a compound index would be speculative, could increase write/storage cost, and might not be selected by the planner. Supabase’s guidance is to inspect the plan, align indexes with observed query patterns, and compare the plan after the change: [Query Optimization](https://supabase.com/docs/guides/database/query-optimization), [Debugging Performance](https://supabase.com/docs/guides/database/debugging-performance), and [Managing Indexes in Postgres](https://supabase.com/docs/guides/database/postgres/indexes).
